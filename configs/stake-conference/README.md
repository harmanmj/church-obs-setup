This Scene Collection is intended for Stake Conference where you want to have the ability to overlay graphics generated by another program and output over NDI. 
It is based upon the dual-camera.json config as it is primarily for use at the Independence building. 

There are two lower third scenes, Lower Thirds - Lyrics and Lower Thirds - Speakers. Each has its own NDI source (Freeshow Lower Thirds - Lyrics and Freeshow Lower Thirds - Speakers). The sources are left blank because the NDI output depends on which computer is running FreeShow, so select the matching output in OBS for each use. Each scene has its own tab in the Downstream Keyer dock, so both can be on air together. Lyrics stays up until it is turned off, and Speaker Names hides automatically after 10 seconds.
